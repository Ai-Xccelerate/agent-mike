# Priority levels and what each means

EAP Expert uses five priorities:

| Priority | What it means |
| --- | --- |
| Critical | The system is down, or no users can do any work. |
| High | Important functionality is unavailable, but most work can continue. |
| Medium | Some functionality is unavailable, without affecting general day-to-day work. |
| Low | Not an immediate need, but it requires attention. |
| Informational | General questions or inquiries. |

Most request types start with a priority of their own:

| Request type | Starting priority |
| --- | --- |
| System Unavailable | Critical |
| General Questions | Medium |
| User / License Change | Low |
| Request a New Feature, Training Request, Professional Services, Suggest Improvement, Security / Compliance Questions | Informational |
| Report a Bug | You choose the priority when you report it. |

The support team reviews the priority when they pick up your request.
