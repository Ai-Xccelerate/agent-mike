# Urgent issues and the high-priority line

If nobody can use the system, if it is unavailable to several users, or if you suspect a data or privacy problem, treat it as urgent.

1. Raise a request using the **System Unavailable** type. It starts at Critical priority.
2. Call the high-priority line: **1-905-702-1380, extension 1**.

For outages, or when a system needs a reboot, the support team will call you to make sure the message is received, and then record the conversation on your request.

If you are describing the problem, share only the technical facts. Please don't include client or patient details.
