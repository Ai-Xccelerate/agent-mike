# Choosing the right support request type

When you raise a request on the EAP Expert Service Desk you choose one of nine request types. Pick the one that fits what you need.

| Request type | Use it when |
| --- | --- |
| Report a Bug | You are running into an error when using one of our products. |
| User / License Change | You want to add or remove a user or a license. |
| Request a New Feature | You have something you want added to the system. |
| General Questions | You have a question, or an issue that doesn't fit anywhere else. |
| Training Request | You want training on a product or service. |
| System Unavailable | The system is unavailable to one or more users because of an issue. |
| Professional Services | You want EAP Expert to do work outside standard support, such as data manipulation, SQL queries, or creating or changing a report. |
| Suggest Improvement | You see an area we could do better. |
| Security / Compliance Questions | You have a security or compliance question. |

If the system is unavailable to your users, use System Unavailable rather than General Questions, and see "Urgent issues and the high-priority line".
