# AIX Theme — Agent Build Spec (READ FIRST)

> Canonical design language: `AIX-DESIGN-SYSTEM.md` (repo root). Read it for
> tokens, agent identity colors (`bg-agent-*` / `AGENT_META`), radius policy
> (controls tuned via `--radius-lg`), voice, and the DS→theme component map.
> This spec covers build mechanics; the design system doc wins on visuals.

You are building pages for a **reusable AIX component library / theme** on
Next.js 16 App Router + React 19 + TypeScript + Tailwind v4. This is NOT a demo
app — components must be **generic and prop-driven** so they drop into any AIX
app. Demo data lives in the page/example component, never baked into a primitive.

## Hard rules (do NOT break — parallel agents rely on this)

1. **Create ONLY the files you are assigned.** NEVER edit any of these shared
   files (the orchestrator owns them): `src/layout/AppSidebar.tsx`,
   `src/app/globals.css`, any `layout.tsx`, `package.json`, `tsconfig.json`,
   `AIX-REFERENCE.md`, or files owned by other agents.
2. **Do not install packages.** Use only what is already in package.json.
3. **Return your nav entries** as structured output (see bottom) so the
   orchestrator can register them in the sidebar.

## File placement

- Admin pages go under a route group in `src/app/(admin)/`. Use the existing
  groups where sensible:
  - `(others-pages)/` for calendar/profile/blank-style pages
  - `(others-pages)/(chart)/` for chart pages
  - `(others-pages)/(tables)/` for table pages
  - `(others-pages)/(forms)/` for form pages
  - `(ui-elements)/` for UI component showcase pages
  - Create new groups like `(dashboards)/`, `(ecommerce)/`, `(apps)/`, `(ai)/`
    when told to. Route groups `(name)` do NOT affect the URL.
- A page at route `/foo` lives at `src/app/(admin)/.../foo/page.tsx`.
- Full-width pages (auth/errors/standalone) go under
  `src/app/(full-width-pages)/`.
- Page-specific components go in `src/components/<area>/<Thing>.tsx`.

## Page template (server component — keeps metadata)

```tsx
import PageBreadcrumb from "@/components/common/PageBreadCrumb";
import { Metadata } from "next";
import React from "react";

export const metadata: Metadata = {
  title: "<Page Name> | AI Xccelerate",
  description: "<one line> in AI Xccelerate",
};

export default function <Name>Page() {
  return (
    <div data-aix-id="<AIX-###>">
      <PageBreadcrumb pageTitle="<Page Name>" />
      <div className="space-y-5 sm:space-y-6">
        {/* blocks: each top-level block gets data-aix-id="<AIX-###>.N" */}
      </div>
    </div>
  );
}
```

## CRITICAL: server/client boundary

- `metadata` can ONLY be exported from a server component (no `"use client"`).
- You **cannot pass functions** (onClick, render callbacks, column.render) from a
  server component into a client component — it throws at runtime.
- So: keep `page.tsx` a server component with metadata, and put ALL interactivity
  (state, onClick, render fns, hooks) inside a separate `"use client"` component
  that the page imports. Example: page imports `<DeploymentsTable/>`, and
  `DeploymentsTable.tsx` (client) defines the columns with render fns.

## Reference IDs (stamp every page)

- Put `data-aix-id="AIX-###"` on the page root div (ID is given to you).
- Put `data-aix-id="AIX-###.1"`, `.2`, … on each top-level component block.

## Brand / styling (reuse = orange for free)

- REUSE existing components — they're already themed:
  - `@/components/common/PageBreadCrumb`, `@/components/common/ComponentCard`
  - `@/components/ui/badge/Badge` (variant: light|solid; color: primary|success|error|warning|info|light|dark)
  - `@/components/ui/button/Button` (size sm|md; variant primary|outline; startIcon/endIcon)
  - `@/components/ui/table` (Table, TableHeader, TableBody, TableRow, TableCell)
  - `@/components/ui/modal`, `@/components/ui/dropdown`, `@/components/ui/avatar`
  - `@/components/tables/DataTable/DataTableOne` (generic `DataTableOne<T>`)
  - `@/components/ui/tabs/Tabs`
  - Icons from `@/icons` (e.g. PlusIcon, BoxIcon, DollarLineIcon, etc.)
- Card shell class (when not using ComponentCard):
  `rounded-2xl border border-gray-200 bg-white dark:border-gray-800 dark:bg-white/[0.03]`
- Brand utilities: `bg-brand-500`, `text-brand-500`, `hover:bg-brand-600`,
  `bg-brand-50`. NEVER use blue/indigo. The brand is orange.
- **Charts (ApexCharts): NEVER use `#465fff`/blue.** Use `colors: ["#F47920"]`
  primary, `"#FAB673"` secondary, `fontFamily: "Open Sans, sans-serif"`. For
  multi-series use `["#F47920", "#FAB673", "#788C5D", "#6A9BCC"]`.
- Text colors: `text-gray-800 dark:text-white/90` (headings),
  `text-gray-500 dark:text-gray-400` (muted).
- Everything must work in light AND dark mode (add `dark:` variants).

## Fluid full-width + mobile responsive (REQUIRED)

- The layout is now full-width (no max-width cap). Design blocks to **fill the
  available width fluidly** — use `w-full`, fluid grids, and `flex-1`; never hard-code
  fixed pixel widths on top-level containers.
- **Mobile-first & responsive.** Every page must look right from ~360px up:
  - Multi-column grids collapse on small screens: e.g.
    `grid grid-cols-1 gap-4 sm:grid-cols-2 xl:grid-cols-4`.
  - Stat/KPI rows: 1 col mobile → 2 col sm → 4 col xl.
  - Two-pane app layouts (chat, inbox, file-manager): stack vertically on mobile
    (`flex flex-col lg:flex-row`), side-by-side on lg+.
  - Wide tables/charts/kanban must scroll inside their own
    `overflow-x-auto` container — the page body must NEVER scroll horizontally.
  - Use responsive padding (`p-4 md:p-6`) and text sizes.
  - Test mentally at 375px, 768px, 1440px, and ultra-wide.

## Design quality bar (modern, professional, user-friendly — REQUIRED)

The AIX aesthetic is **calm confidence**: quiet surfaces, hairline borders, one
orange moment per view. Premium feel comes from discipline, not decoration.

- **One orange moment per view.** Orange (`brand-500`) marks THE primary action
  or key data point on a screen — the main CTA, the active nav, the headline
  series in a chart. Everything else stays greyscale + semantic. If everything
  is orange, nothing is.
- **Hierarchy through type + spacing, not boxes-in-boxes.** Card title
  `text-base font-semibold text-gray-800 dark:text-white/90`, supporting text
  `text-sm text-gray-500 dark:text-gray-400`, data/KPI numbers
  `text-2xl md:text-3xl font-bold tracking-tight`. Never nest a bordered card
  inside a bordered card.
- **Micro-interactions, 150ms ease-out.** Interactive elements get
  `transition-colors duration-150`. Cards: hover shifts the border
  (`hover:border-gray-300 dark:hover:border-gray-700`) — cards never lift or
  grow. Buttons/links: color shift only, no scale.
- **Focus visible.** Keyboard focus uses
  `focus-visible:outline-2 focus-visible:outline-brand-500/50` (or the
  focus-ring shadow token). Never remove focus styles.
- **Empty states are invitations.** Any list/table that can be empty gets an
  icon, one plain sentence ("No agents yet — pick one to get started."), and,
  where sensible, an action. Never a bare "No data".
- **Numbers read naturally.** `1,284` with thousands separators; deltas as
  `↑ 12.4%` in success green / `↓` in error red with a soft pill background
  (`bg-success-50 text-success-600`); friendly time ("2 min ago", "Yesterday").
- **KPI/stat cards**: label-top (text-sm muted), value (bold, tracking-tight),
  delta pill; optional small icon in a `size-11 rounded-xl bg-gray-100
  dark:bg-gray-800` square. No gradients on stat cards.
- **Charts are editorial**: no gridline clutter (`strokeDashArray: 4`, subtle),
  axis labels in gray-400 at 12px, tooltips themed, `sparkline` for in-card
  trends. Headline series = orange `#F47920`; comparison series `#FAB673`;
  never rainbow charts.
- **Gradients: at most one per page**, only on a hero/welcome band
  (`from-brand-500 to-brand-400`), never on components.
- **Copy is UX.** Sentence case everywhere. Buttons say exactly what happens
  ("Save changes", not "Submit"). No emoji in product UI. No lorem ipsum —
  realistic AIX content always.
- **Density with air**: `gap-4 md:gap-6` between blocks; `p-5 md:p-6` inside
  cards; don't cram.

## Quality bar

- Must pass `npx tsc --noEmit` (strict). Type everything; no `any` unless needed.
- No console errors at runtime.
- Realistic AIX-flavored placeholder content (the 6 agents are Nick, Jules,
  Pepper, Tony, Joy, George; product = AI revenue employees). Avoid generic
  lorem where a real label fits.
- Match the visual language of the existing pages (spacing, card style, headers).
