# Sign-in codes

When a teammate requests a sign-in code, Agent Mike can explain the standard flow.

## How codes are sent

1. Open **Settings → Security**.
2. Click **Send sign-in code**.
3. The code arrives by email within **two minutes**.
4. Enter the six-digit code on the sign-in screen.

## If the code never arrives

- Check spam or junk folders.
- Confirm the email address on the account.
- Wait two minutes, then request a new code.
- Codes expire after **10 minutes**.
